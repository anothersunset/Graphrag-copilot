# GraphRAG Copilot API 端点文档

## API 路由列表

所有端点以 /api 为前缀。

### 1. 文档管理
- **POST /api/documents/upload** - 文档上传
  - 接收文件，解析、分块、向量化
  - 后台执行实体抽取与知识图谱导入
  - 依赖: require_api_key 鉴权
  - 支持格式: PDF, DOCX, PPTX, 图片(OCR), 音视频(ASR)

### 2. 问答
- **POST /api/query** - 非流式问答
  - 使用 MultiAgentOrchestrator.process_query 同步返回完整结果
  - 返回: query, answer, sources, analysis, verification, trace, confidence

- **POST /api/query/stream** - 流式问答 SSE 端点
  - 使用 StreamingOrchestrator.process_query_stream
  - 事件流: phase(analysis) → phase(retrieval) → answer_start → token(逐个) → answer_end → done
  - Content-Type: text/event-stream

### 3. 向量检索
- **POST /api/vector/search** - 向量搜索
  - 接收 query 和 top_k，返回相似文档

- **GET /api/vector/stats** - 向量存储统计
  - 返回: type, total_vectors, dimension, total_documents

### 4. 知识图谱
- **GET /api/graph/stats** - 图谱统计
  - 返回: total_nodes, total_relations, node_types, status

- **GET /api/graph/entity/{entity_name}** - 实体查询
  - 参数: depth (默认2)
  - 返回实体的邻居节点

- **GET /api/graph/path** - 路径查找
  - 参数: source, target, max_depth (默认3)
  - 返回两实体间的路径

- **GET /api/graph** - 全量图谱
  - 参数: limit (默认500), type (默认"all")
  - 返回节点+关系，供前端力导向图使用

### 5. 系统
- **GET /api/system/status** - 系统状态
  - 返回: status, llm_model, embedding_model, vector_store, bm25_store, graph_store, auth_enabled, rate_limit_per_min

- **GET /** - 根路径
  - 返回: name, version, status

- **GET /health** - 健康检查
  - 返回: status: "healthy"

## 文档上传完整流程

1. 用户上传文件到 /documents/upload
2. document_parser.parse 解析文件（根据扩展名选择解析器）
3. chunk_text 分块（chunk_size=512, chunk_overlap=50）
4. embedding_service.embed 生成向量
5. vector_store.add_documents 存入 FAISS 向量库
6. bm25_store.add_documents 存入 BM25 索引
7. 后台 background_tasks.add_task 执行 _extract_entities_background
8. llm_service.extract_entities 抽取实体和关系
9. kg_service.ingest_knowledge 通过 UNWIND MERGE 写入 Neo4j
